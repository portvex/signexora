Fonts of the Linux looks (Phase 13), subset to Latin and Cyrillic by
scripts/fonts/linux_subsets.py. They are drawn only where the font itself
is not installed.

Cantarell-Regular-subset.ttf, Cantarell-Bold-subset.ttf
    Cantarell (GNOME), from github.com/google/fonts (ofl/cantarell).
    SIL Open Font License 1.1, see OFL-Cantarell.txt.

NotoSans-Regular-subset.ttf, NotoSans-Bold-subset.ttf
    Noto Sans (KDE Plasma), the 400 and 700 instances of NotoSans[wdth,wght]
    from github.com/google/fonts (ofl/notosans).
    SIL Open Font License 1.1, see OFL-NotoSans.txt.

DejaVuSans-subset.ttf, DejaVuSans-Bold-subset.ttf
    DejaVu Sans 2.37 (GNOME 2, Motif), from github.com/dejavu-fonts.
    Bitstream Vera Fonts licence with public-domain changes, see
    LICENSE-DejaVu.txt.
