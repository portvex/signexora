# SigNexora identity

The cyan waveform N and signal point on a midnight-navy tile are the SigNexora app mark. The PNG master has a transparent exterior. Keep that transparency when exporting icons.

- `signexora.png`: generated master and README logo.
- `signexora-64.png`: embedded icon for window captions and About.
- `signexora.icns`: macOS application bundle icon.
- `signexora.ico`: Windows icon asset for future packaging.

The master was created with the built-in image generation tool. Icon sizes and containers are mechanical exports of the same master.

Regenerate exports with `scripts/icons.sh` on macOS (requires the system `sips` and `iconutil` tools and Python 3).

## Generation prompt

Use case: logo-brand. Asset type: square desktop application icon and brand mark for SigNexora, a signal intelligence tool for radio-signal analysis. Create one polished minimal geometric icon, not a mockup or contact sheet. A bold clean angular N monogram shaped like a sampled radio waveform, with two strong uprights and a descending diagonal connection, paired with a single small signal point near the upper right. Cyan and ice-blue signal mark on a deep midnight-navy rounded square tile. Flat vector-like geometry, precise edges, excellent silhouette and readability at 16 to 64 pixels, generous consistent internal padding. The square tile occupies about 88 percent of the square canvas and is centered. Outside the rounded tile is genuinely transparent. No text, no letters besides the abstract N mark, no tagline, no border decorations, no tiny lines, no shadows outside the tile, no 3D, no photorealism, no watermark. Professional scientific instrument identity.
